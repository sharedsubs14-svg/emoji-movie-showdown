# 🎬 Emoji Movie Showdown

A browser party game for video calls. The host screen-shares, the game shows a movie as emojis, and friends race to type the title in the call chat. The host clicks the winner's name to award points.

- Two editions: **Bollywood** (169 puzzles) and **Hollywood Classics** (145 puzzles)
- Add your own inside-joke puzzles from the setup screen
- Works on laptops (16:9 screen-share) and phones
- Plain HTML, CSS and JavaScript: just open `index.html`

Files: `index.html`, `style.css`, `game.js`, `puzzles.js` (edit this one to add or fix puzzles).
